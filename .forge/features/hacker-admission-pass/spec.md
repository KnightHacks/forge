# Hacker Admission Pass

The user rejected the elaborate ticket design. Replace it with a single flat, mobile-first surface containing only the profile photo/name, class, large QR, and Save QR action. Remove the logo, edition, dates, venue, admission labels, intro/marketing copy, status panel, secondary navigation, and unavailable Wallet button. Both confirmed and checked-in hackers use the same simple layout. Confirmed visitors retain the existing withdrawal control below the pass; other application states stay unchanged.

Use warm ivory and forest green against the established dashboard background. No split panes, nested decorative cards, or new decorative motion. Missing photos use initials; the QR stays high contrast and unobstructed.

## Mobile QR enlargement — October 5 follow-up

The hacker can tap the QR to open a larger, centered scan view. A small “Tap to enlarge” hint and a slow lavender light around the outer edge make this interaction discoverable on mobile. The code and its white quiet zone stay static and unobstructed. This explicitly requested edge animation supersedes the earlier no-new-motion direction for this affordance only. Reduced-motion users see a stationary highlight. Closing the view returns to the dashboard without generating a new QR.
