# Dashboard Atmosphere Performance Spec

Status: Approved for implementation

## Purpose and scope

Keep the Knight Hacks IX dashboard's forest atmosphere while reducing continuous
graphics work for signed-in hackers. The user approved making the fog, canopy
glow, and wisps static while retaining the moving fireflies on October 9, 2026.

## Acceptance criteria

- Fog, canopy glow, and wisps remain visible in their existing positions without
  animation.
- Fireflies continue moving under the normal motion preference.
- Reduced-motion users continue to receive a static atmosphere.
- Dashboard layout, content, navigation, and interactions remain the same.

## Open questions

- None. The requested change is confined to the dashboard atmosphere.
