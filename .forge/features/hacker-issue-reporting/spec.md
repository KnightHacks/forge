# Hacker issue reporting

Hackers can report event problems from the 2026 dashboard. Send report delivers their description and Discord identity to organizers; success appears only after Discord accepts delivery. Errors preserve the draft.

Officers configure the private channel and optional role to ping for each event from Blade's Hackathons page, per Dylan's request. Clearing the channel disables reporting. Clearing the role sends without a ping. Hacker-written mentions must not ping arbitrary users or roles.

This is the first branch of the user's requested stack. Judging-score privacy is a separate second branch.
