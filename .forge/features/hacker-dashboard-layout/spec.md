# Hacker Dashboard Layout

Confirmed and checked-in hackers see their photo, name, assigned class, project team, QR, and résumé controls at `/dashboard`. User explicitly chose both class and project team.

Latest direction: a compact pass at the top of the page, without the green top border or extra role/event/status copy. Keep the core actions in the first small-phone screen; mobile résumé management opens a dialog. Desktop résumé controls fill the space beside the QR. View, download, and upload/replace use the existing résumé workflow and deadline.

Profile photos have no decorative ring. Use the photo saved in Blade first, then the Discord avatar, then initials when no image is available.

Use a distinctive violet-to-teal gradient with the supplied Knight Hacks SVG forest objects, layered trunks, hanging vines, foreground leaves, animated fireflies, and wisps. Scenery extends beyond the edges and stays behind content. Preserve reduced-motion support.

Class palettes follow the supplied badges: Petalborn mint, Dryad olive, Whisperseed aqua, Chomper pink, Spora lavender, Collosus cyan/violet. Coordinate class text and avatar; unknown classes retain gold. QR stays black on white. Use the user's corrected spelling, Collosus; existing Colossus values display as Collosus on the dashboard.

Apple Wallet was removed at the user's request. Keep the web check-in QR and résumé controls; no Wallet export or certificate setup is part of this feature.
