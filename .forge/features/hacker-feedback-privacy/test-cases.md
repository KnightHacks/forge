# Regression checks

- A completed member evaluation includes public feedback, a private organizer note and an optional response with sharing off. The hacker receives only public feedback; neither hidden label nor hidden value appears in the DTO.
- Guest and incomplete evaluations remain excluded; numeric rating labels/values and judge identity remain absent.
- Emergency mode returns no feedback; leaving emergency mode restores only public responses.
- Reload the local hacker feedback dialog after a judge submits a private marker. The marker remains stored for judges but disappears from the hacker view.
