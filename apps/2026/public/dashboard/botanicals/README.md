# Dashboard artwork

Source: Knight Hacks' `KHIX Mentorship.ai` Illustrator document and the individual-object export dated 2026-10-04.

These web copies contain native paths and gradients recovered from the original Illustrator objects. The earlier SVG exports embedded low-resolution PNGs because of Illustrator's raster appearance effects. Do not replace these with bitmap-backed SVGs: the scenery is intentionally displayed larger than the original artwork. Keep grain in the shared procedural background layer, separate from the vector edges.

The original export viewBoxes and object offsets are retained so replacing the files does not change layout. The source AI document and original Downloads exports were not modified.
